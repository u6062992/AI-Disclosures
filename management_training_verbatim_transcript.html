You can bootstrap it pretty cleanly with the `boot` package. The idea is: repeatedly resample the trimmed dataset, refit the weighted model each time, and save the `intervention` coefficient. ```r library(boot) # Function to refit the IPW model on a bootstrap sample boot_ipw <- function(data, indices) { boot_data <- data[indices, ] fit <- lm( engagement_score ~ intervention + tenure + n_of_reports + gender + role + last_engagement_score + department_score + department_size, data = boot_data, weights = ipw ) coef(fit)["intervention"] } # Run 1,000 bootstrap samples set.seed(123) boot_results <- boot( data = trimmed_d, statistic = boot_ipw, R = 1000 ) # View bootstrap results boot_results # 95% bootstrap confidence interval boot.ci(boot_results, type = "perc") ``` The part you care about at the end is the **percentile interval** from: ```r boot.ci(boot_results, type = "perc") ``` That will give you a lower and upper 95% bootstrap confidence interval. One caveat: this version keeps the already-calculated propensity scores and IPW weights fixed during each bootstrap sample. For a more rigorous bootstrap, you would re-estimate the propensity-score model and weights inside every bootstrap sample too. If your professor just says “bootstrap the CI,” this simpler version is probably much more in line with the level of the module.
